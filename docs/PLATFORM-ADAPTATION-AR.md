# نتيجة فحص وترحيل سند تعز إلى Manus

## النطاق المنقول

نُقلت واجهة React/Vite وخادم Express ومكتبات PostgreSQL/Drizzle ومخططات Zod وعميل API والأصول التشغيلية من الأرشيف إلى المشروع المُدار. أُبقيت الصفحات والسلوك الموجود في المصدر، وأُضيف بيان المسارات للصفحات الـ17. استُبعدت الاعتماديات والمخرجات المولدة وقواعد البيانات الاحتياطية والحزم الثنائية غير المناسبة لـLinux وملف `.env`؛ لا توجد أسرار تشغيل فعلية في المشروع.

## الفحوص المنفذة

| الفحص | النتيجة |
| --- | --- |
| `pnpm install --frozen-lockfile` | ناجح، باستخدام pnpm 11.25.0 |
| `pnpm run build` | ناجح؛ يتضمن فحص TypeScript للمكتبات وخادم API والواجهة وحزمة scripts، وبناء Vite وExpress |
| تشفير الحجز | ناجح ببيانات اصطناعية: تشفير/فك التنسيق v2 وفك التنسيق القديم |
| سياسة Origin/CSRF | ناجح دون قاعدة بيانات: رفض Origin المفقود وغير الموثوق، والسماح بـlocalhost في التطوير وبالأصل المدرج في `CORS_ORIGINS` |
| `GET /` للمعاينة | HTTP 200، `text/html` |
| `GET /manus-routes.json` | HTTP 200، `application/json`؛ 17 مساراً فعلياً، لا HTML احتياطي |
| الملفات/البيئة الحساسة | لا يحتوي مجلد التشغيل على `.env` أو قواعد SQL/نسخ احتياطية |

## إصلاحات المراجعة

- جلسة HTTPS تستخدم `SameSite=None; Secure` افتراضياً. لا يُقبل `COOKIE_SECURE=false` إلا مع `NODE_ENV=development` للتشغيل المحلي عبر HTTP.
- تُرفض طلبات `POST/PUT/PATCH/DELETE` التي لا يأتي `Origin` فيها من `CORS_ORIGINS` أو localhost/127.0.0.1 في التطوير؛ أدرج الأصل الدقيق للواجهة عند تشغيل API.
- بيانات التواصل للحجوزات تستخدم `BOOKING_ENCRYPTION_KEY` مستقلاً عن `SESSION_SECRET`. تُحفظ السجلات الجديدة بتنسيق إصدار مميز، مع استمرار فك السجلات القديمة التي تستخدم مفتاح الجلسة السابق.
- يفحص رفع الصور الامتداد وMIME وتوقيع بايتات المحتوى قبل حفظ الملف؛ الحد 5 MB والامتدادات JPG/JPEG/PNG/WEBP/GIF فقط.
- تتحقق واجهة الإدارة من رموز استجابة HTTP قبل إظهار نجاح الحذف أو إعدادات واتساب. عولج إرجاع تفاصيل خطأ PostgreSQL لواجهة التمارين العامة.
- أزيل قيد تكبير الصفحة، وأزيل حذف ملفات قفل npm/Yarn تلقائياً أثناء التثبيت.
- توضّح صفحة الخصوصية أن المذكرات وورقة التفكير والامتنان وبعض التفضيلات تُحفظ في `localStorage` غير المشفر حتى حذفها؛ أضيف خيار لمسح جميع مذكرات «المساحة الآمنة»، وأزيل ادعاء الحذف خلال سبعة أيام غير المدعوم بآلية.
- أزيلت شهادة شخصية ثابتة غير موثقة من صفحة المساحة الآمنة، واستبدلت بنص لا ينسب تجربة إلى مستخدم دون موافقته.
- لا يرسل الموقع `X-Frame-Options: DENY/SAMEORIGIN` بما يمنع عرض Preview داخل iframe؛ بقيت الترويسات الوقائية الأخرى.

## ما يمنع تشغيل البيانات أو الإطلاق الإنتاجي الآن

1. **قاعدة البيانات:** تحتاج وظائف المحتوى والحجز ولوحة الإدارة إلى `DATABASE_URL` حقيقي لـPostgreSQL. لم يقدّم المستخدم اتصالاً؛ لم تُطبق migrations أو `drizzle push` ولم يُنشأ حساب أو محتوى.
2. **تهيئة الخادم:** يزرع بدء خادم API محتوى أولياً، وقد ينشئ المدير الأول إذا ضُبطت بياناته. لم نشغّله تفادياً لأي كتابة غير معتمدة في قاعدة مشتركة. يجب مراجعة ما سيُزرع والموافقة على التغييرات قبل ربط أي قاعدة مستخدم.
3. **الإعدادات السرية:** التشغيل الفعلي يتطلب `SESSION_SECRET` و`BOOKING_ENCRYPTION_KEY` منفصلين وثابتين، و`ADMIN_EMAIL` و`ADMIN_PASSWORD` حقيقيين عند إنشاء المدير الأول. سجلات التشفير القديمة تعتمد على `SESSION_SECRET` القديم؛ لا تدوّره قبل خطة إعادة تشفير.
4. **Origins وCSRF:** أدرج الأصل الدقيق للواجهة في `CORS_ORIGINS`؛ يلزم لطلبات التعديل المحمية بـ`Origin` ويشمل عنوان HTTPS إذا استُخدم API من المعاينة.
5. **الرفع:** الملفات تُكتب حالياً إلى `artifacts/sanad-taiz/public/uploads`. ملفات الحاوية المنشورة مؤقتة؛ انقلها إلى تخزين دائم قبل تمكين رفع ملفات حقيقية أو نشر التطبيق.
6. **بيانات المتصفح:** الملاحظات المحلية غير مشفرة وتبقى حتى حذفها. لا توجد في هذه النسخة قناة آلية لمعالجة طلب حذف بيانات الخادم أو مهلة حذف مضمونة؛ لا تُدخل بيانات حساسة حقيقية قبل اعتماد سياسة حذف مناسبة.
7. **مسار النشر:** المسارات والأصول في المصدر جذرية مثل `/...`؛ يعتمد هذا الترحيل النشر تحت `/` فقط إلى أن يُنفّذ دعم واختبار واضح لمسار فرعي.

## تشغيل محلي آمن

بعد مراجعة المخطط وقرار استخدام قاعدة غير إنتاجية، أنشئ `.env` من `.env.example` وأدخل أسراراً عشوائية طويلة، ولا ترفع `.env` مطلقاً. استخدم `COOKIE_SECURE=false` فقط على localhost HTTP مع `NODE_ENV=development`. راجع seed والمخطط ثم طبّق الترحيلات يدوياً على قاعدة اختبار مصرح بها؛ لا تستخدم قاعدة الإنتاج للاختبارات.
