# سند تعز — نسخة إعادة الهيكلة

تتضمن هذه النسخة إعادة فصل صفحات `App.tsx`، وتقسيم CSS إلى طبقات مرتبة، وإضافة تحميل كسول للصفحات.

## أهم التغييرات

- أصبح `App.tsx` مسؤولاً عن تركيب التطبيق والمسارات فقط.
- فصل الصفحات إلى 12 وحدة داخل `artifacts/sanad-taiz/src/pages/`.
- فصل المكونات المشتركة إلى وحدات متخصصة داخل `artifacts/sanad-taiz/src/components/`.
- تحميل الصفحات عند الحاجة باستخدام `React.lazy`.
- تقسيم CSS إلى أربعة ملفات مرتبة مع الحفاظ على تسلسل القواعد.
- الإبقاء على قاعدة البيانات ومخططها دون تغيير.
- عدم تضمين ملف `.env` الفعلي؛ استخدم `.env.example` وأنشئ ملفك محلياً.

## التحقق

نجحت فحوص صياغة TypeScript/TSX، ومسارات الاستيراد المحلية، والتصديرات المحلية، وتحليل CSS. تعذر تشغيل تثبيت الحزم والبناء الكامل في بيئة إعداد النسخة بسبب عدم الوصول إلى npm registry.

نفّذ من مجلد المشروع:

```bash
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm run build
```

ثم اختبر الخادم والواجهة والصفحات وتسجيل الدخول والحجز ولوحة الإدارة ورفع الصور قبل النشر.

للتفاصيل راجع `docs/REFACTOR-REPORT.md`.
